사용자가 이전 정교화는 차이를 느끼기 어렵다고 피드백하여 차량 이외의 화면 구조를 새로 구성했다. **이번 변경은 HTML 디자인이며 Android에는 적용하지 않았다.** 기존 Android 검증/CI 성공은 `9996018` 기준이다. 팀원 제품 코드·공통 계약·DB·SDK·서비스·내비는 이번 브랜치에서 변경하지 않았다.

브랜치: `feat/history-b-layout-redesign`, 기준: `9996018`. 기존 기록 연결 브랜치와 main에는 병합하지 않는다.

## 새 구성

- 첫 화면: 중앙 차량, 왼쪽 출발 준비/탑승자, 오른쪽 환경·경로/조언, 아래쪽 가로 운행 목록. 큰 최근 운행 외곽 카드를 제거했다.
- 메뉴: 데스크톱은 상단 중앙, 태블릿/모바일은 떠 있는 하단 메뉴.
- 기록: 날짜 선택을 가로로 옮기고 외곽 카드를 제거해 그래프와 응답을 넓게 배치했다.
- 프로필: 인물 카드 대신 열린 목록, 상세는 인물/지표/기록 영역으로 나눴다.
- 평가·종료·환경·경로·조언: 위계·구분선·절제된 재질·큰 수치 중심으로 정리했다. 평가 저장은 일반 입력 버튼으로, 조언에는 사선 표면을 유지했다.
- 원본 차량·얼굴 자산을 보존했다. 작은 운행 곡선도 같은 replay 표본을 쓰고 기록 공백은 연결하지 않는다. 지영의 3건, 운전자별 조회·좌석·평가·프로필 처리와 상세 감속 그래프는 유지한다.

## 검증

- 기존 HTML 시나리오·조언·replay Node 검사 3개 통과.
- 9개 화면 × 1600/1024/768/390의 36개 배치에서 바깥/메인 가로 넘침 없음. 1600×1000, 1024×768, 390×844 캡처 각 9장 보존.
- 모바일 실제 포인터로 조수석 선택→도윤 배치→j2 기록→평가 4점·출발/정차→저장→종료를 확인했다. 저장은 HTML 격리 시연의 j2/4점이며 실제 사용자 DB와 무관하다.
- 리뷰에서 인물 목록을 키보드로 열면 BODY로 초점이 사라짐을 재현했다. 서랍 진입·Tab 순환·Escape 닫기·호출 인물로 복귀를 구현한 뒤 모두 통과했다. 화면 도구도 44px로 수정했다.
- 4명 탑승 시 모바일 인물 목록은 2×2로 배치되며 329px 영역을 넘지 않는다. 모션 감소 설정에서 화면 전환 애니메이션이 꺼짐을 확인했다.
- 루트 파일을 기준 커밋과 대조하고 사본을 보존한 뒤 index/app/review와 새 layout.css만 동기화했다. 그 밖의 미커밋 파일은 보존했다.
