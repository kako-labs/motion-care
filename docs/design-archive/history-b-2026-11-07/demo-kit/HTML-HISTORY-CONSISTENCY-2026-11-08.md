# HTML 운행 기록 일관성 수정 · 2026-11-08

사용자가 본 출발 안내에는 기록이 없고 운행 기록에는 두 운전자의 6건이 섞여 있었다. HTML 시제품만 수정했다.

- `?driver=jiyoung`을 첫 화면 렌더링 전에 적용한다. 기존 좌석 저장 상태와 충돌해도 지영을 운전석에 한 번만 배치한다.
- 출발 안내와 운행 기록 모두 현재 운전자의 동일한 3건을 사용한다. 다른 운전자의 상세가 선택돼 있으면 현재 운전자의 최신 기록으로 맞춘다.
- 운전자를 직접 바꾸면 그 운전자의 기록으로 전환한다. 사용자가 운전석을 비우는 경우에는 다른 사람의 상세를 남기지 않는다.
- 기존 B 디자인, 상세 감속 그래프와 합성 기록을 유지했다. Android 코드·공통 계약·서비스·실제 DB 변경은 없다.

검증: `history-scenario.test.cjs`, `advice-context.test.cjs`, `journey-replay.test.cjs` 통과. 브라우저에서 출발 안내 → 운행 기록 → 조언 모두 `j1/j2/j3`, 지영 운전, 최신 `j1`로 일치함을 확인했다. 조수석 지영/운전석 빈 값의 오래된 저장 상태를 재현한 뒤 다시 열어도 양쪽 3건으로 복구된다.

수정 전 파일은 로컬 `artifacts/html-history-consistency`에 보존했다. 기존 미커밋 변경은 유지하며 별도 Android 작업 브랜치의 디자인 아카이브에도 이번 HTML 소스와 검사를 저장한다. 공유 main 병합과 원격 push는 하지 않는다.
