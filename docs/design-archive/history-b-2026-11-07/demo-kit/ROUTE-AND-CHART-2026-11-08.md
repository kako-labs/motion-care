# 경로 비교와 기록 그래프 재설계

## 사용자 결정

지도와 경로가 실제 도로에 맞아야 한다. 그래프의 목적과 읽을 정보를 먼저 정한다. 제품 화면의 목업·합성·면책성 문구는 제거하고 구현 상태는 문서와 데이터 메타정보에 보존한다. 이 지시는 기존 시안의 UI 내 합성 라벨·의학적 면책 문구 표기 방식을 대체한다. 값 없음·권한·오래된 값, 예측 출처와 지도 저작권처럼 사용자가 판단하는 데 필요한 정보는 유지한다.

## 경로 화면

OpenStreetMap 도로·공원·수로와 OSRM 경로 응답을 가져와 **같은 지리 좌표 투영**으로 그렸다. 도로와 무관한 장식선이나 임의의 매끈한 곡선을 경로로 쓰지 않는다. 원본 출처·라이선스·재현 요청은 `ui-review/selected-b/assets/MAP-SOURCES.md`에 있다.

두 후보는 양재역 부근 → 봉은사역 부근이다. 5.6km의 짧은 길과 5.8km의 회전 안내가 적은 길을 비교한다. 교차로 좌·우회전 안내는 각각 4회와 2회다. 시간은 저장된 OSRM 응답의 추정값이며 교통 미반영을 화면에 표시한다. 이는 실제 Pleos COMFORTABLE 호출 결과가 아니다. 선택은 브라우저 상태만 바꾼다.

### 멀미 부담을 줄이는 경로를 발전시키는 기준

| 볼 항목 | 필요한 입력 | 현재 판단 |
| --- | --- | --- |
| 교차로 좌·우회전 | 경로 maneuver | 두 후보 비교에 사용. 물리적인 모든 곡선의 수와는 다름 |
| 급한 곡선·연속 S자 | 충분히 촘촘한 경로 곡률과 해당 구간 속도 | 단순 회전 횟수로 대체하지 않음. 구현 후 곡률과 속도로 횡방향 움직임 부담을 살펴볼 후보 |
| 반복 정차·가감속 | 신호·교통·시간대별 속도 이력 | 현재 수집되지 않은 신호·정체 횟수를 만들어 넣지 않음 |
| 방지턱·불규칙 노면 | 위치가 확인된 traffic_calming, surface, smoothness 또는 검증된 노면 자료 | 미확인은 '없음'으로 처리하지 않음. 포장 재질만으로 평탄함을 판단하지 않음 |
| 이동시간 | 같은 기준의 ETA와 지연 허용 | 과도한 우회와 노출시간 증가도 함께 비교. 무조건 긴 길을 추천하지 않음 |

다음 단계는 후보별 시간·회전·곡률·노면 정보의 확인 범위를 나란히 보여주는 것이다. 검증되지 않은 가중치로 '멀미 점수'나 '멀미 없는 길'을 만들지 않는다. 이번에는 지도·두 경로 비교·회전 수만 실제 공개 데이터에 근거한다. 팀원의 내비·탐지·차량 서비스는 변경하지 않았다.

### 확인한 1차 자료

- [Pleos NaviHelper Routes](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/NaviHelper/routes): COMFORTABLE은 편안한 경로 옵션이며 옵션 변경은 콜백으로 확인해야 함. 급커브·요철을 모두 피한다는 상세 보장은 확인하지 못함.
- [OSRM API](https://project-osrm.org/docs/v5.24.0/api/): 경로 geometry·duration·distance·maneuver를 읽는 근거.
- [OSM smoothness](https://wiki.openstreetmap.org/wiki/Key:smoothness), [surface](https://wiki.openstreetmap.org/wiki/Key:surface), [traffic_calming](https://wiki.openstreetmap.org/wiki/Key:traffic_calming): 평탄함·재질·방지턱 정보는 서로 다른 태그. 태그 누락은 요철 없음이 아님.
- [Souman 외, 2026](https://pubmed.ncbi.nlm.nih.gov/42240048/): 가속 방향·주파수·크기에 따른 실험 연구. 도로별 멀미 예방 보장이나 단일 임계값으로 전환하지 않음.
- [Car sickness in real driving conditions, 2023](https://doi.org/10.1016/j.trf.2023.06.018): 횡가속도와 예측 가능성에 관한 실도로 실험. 단순히 곡선 개수만 세어 개인 멀미를 예측하는 근거로 쓰지 않음.

## 그래프의 목적과 표시

**질문: '이동 중 언제 속도가 크게 줄었고, 얼마나 빠르게 줄었나?'**

- 가로축: 실제 시각. 세로축: km/h. 속도선을 장식용 13점이 아닌 1Hz 시계열로 교체.
- 주황 점·번호: 정차 전 큰 감속 구간. 버튼과 일대일 대응.
- 구간 선택: 시각·출발 후 경과시간·감속 전후 km/h·걸린 초를 표시.
- 마우스/포인터: 해당 시각의 속도와 경과시간을 표시.
- 1분의 미수집 구간: 선을 끊고 별도 배경으로 표시. 보간하지 않음.
- 거리: 유효한 인접 1초 표본만 사다리꼴 적분. 유효 분석시간·표본 수·목록·상세·평가 거리도 같은 데이터에서 계산.

`journey-data.js`는 결정론적 **합성 리플레이 fixture**다. 실제 사람·차량에서 측정한 기록이 아니다. 도심의 정차·완만한 가감속과 큰 감속을 불규칙하게 배치했고 속도·거리·시간·마커가 서로 맞게 만들었다. 구간 마커는 fixture의 사건 메타데이터이며 실제 탐지기를 다시 구현하거나 새 멀미 임계값을 만든 것이 아니다. 다른 패턴·프로필·피드백도 여전히 화면 개발용 데이터다.

실제 앱에서는 저장 `SpeedSample`과 `Observation`을 함께 받아 같은 시간축에 그려야 한다. 탐지 임계값·탐지기·저장 규칙 변경은 이 작업에 포함되지 않는다.
