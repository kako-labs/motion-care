# 90초 촬영 순서

기본 편집안이며 제출 규격을 새로 정한 것은 아니다. 실제 앱 영상과 HTML 콘셉트 컷을 구분한다. 주행 담당의 시연 입력이나 안내 정책을 바꾸지 않는다.

| --- | --- | --- | --- |
| 00–08 | 출발 화면, 운전자·동승자 좌석 | 함께 타는 사람을 기준으로 이동을 준비 | B 화면은 `UI 시제품 · 합성 데이터` |
| 08–18 | 실내·외부 환경 열기 | 실내 측정 온도·설정 온도와 바깥 대기질을 구별 | B 화면은 합성. 실제 앱 연결 후에는 차량/예측 출처·시각 표시 |
| 18–28 | 경로 두 옵션 선택 | 시간·거리 비교와 선택 상태 | `경로 기능 콘셉트 · 실제 탐색 미연결` |

## 촬영 전 세팅

- Chrome 확대 100%, 타깃 차량 화면은 1682×1210을 기준으로 준비. 더 작은 화면은 내용을 스크롤한다.
- 브라우저 시제품은 `review.html`에서 화면을 고르고, `시연 도구 → 처음으로 초기화`로 같은 출발 상태를 재현한다.
- 실제 에뮬레이터 구간은 팀 저장소 README와 `docs/pleos-emulator/`에 있는 기존 도구·기기 설정을 따른다. 이 문서에서 ADB 값을 임의로 대체하지 않는다.
- 최종 녹화에는 다른 앱 알림과 계정·개인 파일 경로가 보이지 않게 앱 영역을 캡처한다.
- 직접 촬영 전 `MERGE-HANDOFF.md`의 통합 확인을 끝낸다.

## 예비 컷

환경 권한 거부·네트워크 없음·오래된 값은 B 화면 상단 시연 도구에서 바꾼다. 경로 실패는 `내비 연결 실패 상황 보기`로 재현한다. 제품 동작과 다른 개발 도구가 영상에 필요하지 않으면 컷 사이에 설정하고 닫는다.

## 짧은 내레이션 초안

“모션케어는 함께 타는 사람을 기준으로 이동을 준비합니다. 출발 전에는 개인 선호와 실내·외부 환경을 구별해서 살펴봅니다. 이동 중에는 관찰된 움직임에 따라 짧은 안내를 전하고, 도착 후에는 동승자가 편안함과 불편했던 순간을 남길 수 있습니다. 이 기록은 다음 출발을 준비하는 참고가 됩니다. 경로 비교는 확장 콘셉트이며, 멀미 감소를 보장하거나 멀미를 진단하지 않습니다.”
