## 브라우저 시제품

- Chrome 1682×1210에서 출발·운행 상세·동승자 프로필·운전자 프로필·평가·환경·권한 없음·경로를 렌더하고 캡처를 직접 확인했다. 캡처: `../ui-review/selected-b/previews/v4/`.
- 1682×1210, 1440×740, 840×1210, 390×844의 7개 화면을 레이아웃 하네스로 확인했다. 총 28개 조합에서 문서 가로 넘침·화면 내부 버튼/이미지의 좌우 잘림·깨진 이미지가 없었다. 작은 화면은 세로 스크롤한다.
- Ego 브라우저 실제 클릭으로 4점·커브 저장 → 종료 → 상세 반영, 건너뛰기의 미응답, 경로 선택과 실패 시 기존 경로 유지 문구, 프로필 선호 편집, 데모 초기화를 확인했다.
- 환경 값 있음/권한 없음/네트워크 없음/미지원/오래된 값/확인 중 상태를 순회했다. 값이 없는 경우 대기질은 `—`이며 오래된 값에는 상태가 남는다.
- 코드 구문 검사는 `node --check app.js`, `node --check demo-extras.js`. 이미지 캡처는 Ego의 `Page.captureScreenshot` 시간 초과로 Chrome headless를 사용했다. DOM과 클릭 검증은 Ego에서 수행했다.

결과 JSON: `previews/v4/interaction-checks.json`, `previews/v4/layout-checks.json`. 브라우저에서 실제 차량 SDK·대기질 API·내비 탐색을 실행하지 않았다.

## Android 표시 준비물

공유 main `4fd34ebe448144124d29662d4fa9f805f39e4d80`에서 시작해 문서 갱신 `fae2f54cb7ea56c1a2b01b3641318c61eb540b3a`까지 반영한 `feat/history-presentation-kit` 브랜치에서 검사했다. 변경은 기록 담당 표시 코드와 테스트·인계 문서뿐이다.

- 실행: JDK 17, compileSdk/build tools 35, 저장소 표준 `python scripts/dev.py verify`.
- 결과: build·architecture 검사·lint·단위 테스트 통과. 전체 260개 테스트, 실패 0. 새 환경 표시 테스트 3개 포함.
- 새 테스트는 없는 값을 0으로 표시하지 않는지, 오래된 값의 시각·출처가 유지되는지, 로딩·미지원·권한·네트워크 상태가 구별되는지 확인한다.
- 기존 SDK 처리/차량 API/Gradle의 경고는 남아 있으며 타 담당 코드를 수정하지 않았다.
- B 표시 컴포넌트는 기존 화면 호출부에 아직 연결하지 않았다. 실제 에뮬레이터에서 새 화면을 띄워 보거나 실차를 검증한 결과가 아니다. 내비게이션·수명주기 코드는 바꾸지 않았다.
