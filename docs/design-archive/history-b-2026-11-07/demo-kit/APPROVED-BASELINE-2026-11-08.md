# 사용자 확인을 받은 화면 기준 · 2026-11-08

감속 그래프와 기록 있는 기본 화면을 수정한 뒤 사용자가 “좋아 잘 기록해줘”라고 확인했다. 이후 화면 작업과 통합 시 이 상태를 기준으로 삼는다.

## 유지할 화면 방향

- 선택한 B의 네이비·하늘색, 유리 질감과 사선 제안 패널을 유지한다.
- 왼쪽은 큰 차량과 실제 좌석 위치에 맞춘 인물 선택, 오른쪽은 최근 운행과 하단 제안으로 구성한다.
- 인물은 다듬은 얼굴 자산을 사용한다. 좌석 위치는 차량 그림으로 이해할 수 있게 한다.
- 제품 화면에는 반복적인 목업·합성·면책 문구를 다시 넣지 않는다. 데이터 출처와 구현 범위는 개발 문서와 메타데이터에 남긴다.

## 이번에 확정한 기본 상태

- 별도 URL 인자 없이 지영 운전·서아 동승으로 시작한다.
- 지영의 운행 기록 3건(j1~j3)을 표시하고 최근 운행 j1을 선택한다.
- 이유 보기에는 감속 4회, 이번 1.3회/10분, 직전 2회 평균 2.1회/10분이 나타난다.
- 새로 열기·초기화·이전 빈 시나리오에서의 재진입도 기록이 있는 상태로 시작한다.
- 실제로 기록이 없는 운전자를 다루는 빈 상태 기능은 남기되, 기본 시연을 빈 상태로 되돌리지 않는다.

## 감속 그래프 기준

- 몇 점을 직선으로 이은 도형 대신 감속 전 주행 → 점진적인 제동 → 정차 대기 → 재출발의 흐름을 보여준다.
- 감속 전 24초와 정차 후 36초를 함께 표시한다. 선택 구간은 별도 색과 시작·끝 표시로 강조한다.
- 가로축은 시각, 세로축은 km/h다. 포인터로 시각과 소수점 속도를 읽을 수 있다.
- 상세 0.2초 표본과 전체 1초 표본의 공통 시각 값이 일치한다. 감속 번호를 선택한 뒤 운행 상세로 이동하면 같은 운행·같은 사건이 열린다.
- 실제 차량 측정 자료가 아닌 합성 리플레이라는 출처는 코드와 개발 문서에 유지한다. 화면의 세밀한 표현을 실제 수집 정확도의 증거로 사용하지 않는다.
