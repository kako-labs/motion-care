# 운전 패턴 탐지 기준의 근거

`PatternLimits`와 `LateralLimits`의 값마다 출처와 확인 수준을 적습니다. 값을 바꾸면 이 표와 [`detection-limits/detector.py`](detection-limits/detector.py)를 함께 고칩니다.

## 먼저 알아 둘 점

- **이 값은 멀미 기준이 아닙니다.** 주행을 기록할 때 쓰는 구분선입니다. Souman 외(2026)에서 증상은 시험 범위(0.5~4.0m/s²) 전체에서 가속도가 커질수록 커졌고, 여기부터 멀미가 난다는 문턱은 보고되지 않았습니다.
- **탐지와 안내는 별개입니다.** 관찰로 기록되는 횟수만큼 주행 중 카드를 띄우지 않습니다. 안내 빈도는 [안내 카드의 근거](guidance-card.md)에서 따로 정합니다.
- **위험 기준이 아니라 승차감 기준으로 잡았습니다.** 기획의 차별점이 "안전 기준 이내라도 반복되는 출렁임 관찰"이므로, 사업용 차량의 위험운전 기준은 참고선으로만 씁니다.

## 값과 근거

근거 유형: **연구**(논문·측정 자료) / **실측**(우리가 측정) / **제품 판단**(근거 없음, 이유만 있음) / **구현 판단**(계산 안정성을 위한 값).

| 값 | 현재 | 유형 | 근거 |
| --- | --- | --- | --- |
| `rapidStartMps2` 빠른 출발 | 2.0m/s² | 연구·실측 | 좌석 승객 권장 한계 2.0(Bae 외 2019의 인용). 사람 운전의 가속은 주행 시간 99.9%에서 약 2 이내(Bosetti 외 2014). 실도로 안내 연구의 가장 관대한 상한 1.89(Xie 외 2026). 버스(2.22)와 택시(2.78)의 급출발 기준보다 낮음 |
| `hardStopMps2` 정차 직전 큰 감속 | 2.0m/s² | 연구·실측 | 제동은 주행 시간 99.9%에서 약 −0.5~−2(Bosetti 외 2014). 편안한 제동 영역 −2 이내(Bae 외 2019가 인용한 Moon·Yi 2008). 일반 감속 평균 1.86~2.16(Danaher 외 2022)의 위쪽. 공단의 모든 급정지 기준(2.22~3.89)보다 낮음 |
| `rapidStartWindowMs` | 3초 | 연구 | 대부분 출발 후 1~3초 구간에서 가속이 가장 큼(Danaher 외 2022) |
| `hardStopWindowMs` | 5초 | 연구 | 대부분 정차 전 약 5초 이내에 최대 감속에 도달(Wang 외 2005) |
| `swingMps2` 반복 가감속 크기 | 0.9m/s² | 연구 | 멀미 실험의 종방향 1.0m/s²(최대) 조건을 1초 구간으로 재면 0.2Hz에서 0.94, 0.06Hz에서 0.99(계산)여서 잡히는 값(Souman 외 2026, Golding 외 2001). 사람 운전 가감속의 90%가 −0.89~0.96(Bosetti 외 2014). 실도로 안내 연구의 상한 0.89(Xie 외 2026) |
| `swingWindowMs` | 30초 | 연구 | 전환 3번은 한 주기이므로 0.033Hz 이상을 잡음. Souman 외(2026)가 종방향 1.0m/s² 이상으로 시험한 0.06~0.2Hz를 모두 포함 |
| `swingCount` | 3번 | 제품 판단 | 연구 근거 없음. 기획서의 정의(가속→감속→가속→감속)를 따름. 실험은 20~30분 지속 노출이라 몇 번부터 문제인지 말해 주지 않음 |
| `accelerationWindowMs` | 1초 | 구현 판단 | 기획서의 속도 변화÷시간 근사. 공단 기준도 "초당" 단위 |
| `minAccelerationSpanMs`, `maxGapMs` | 0.5초, 1초 | 구현 판단 | 에뮬레이터 수신 간격(중앙값 약 200ms)에서 1초 구간을 계산할 수 있는 범위 |
| `stoppedBelowMps`, `movingAboveMps` | 0.5, 1.0m/s | 구현 판단 | 정차 부근 값이 흔들려도 상태가 반복해서 바뀌지 않게 하는 간격. 공단은 5km/h(1.39m/s)를 씀. 실차 저속 신호로 확인 필요 |

`RAPID_START`의 2.0은 화물차 급출발 기준(1.67)보다는 높습니다. 승객을 태우는 차량 기준보다 낮다는 뜻입니다.

### 좌우 움직임

조향각과 속도로 횡가속도를 **추정**합니다. 추정식은 `속도² × tan(조향각 ÷ 조향비) ÷ 축거`입니다. 차량의 횡가속도나 요레이트를 주는 API는 찾지 못했습니다.

왜 넣었는지: 실제 도로 측정에서 횡방향 멀미 노출이 종방향의 약 2배였고(`MSDV` 20.70 대 10.83, Harmankaya 외 2025), 버스·코치 승객 3,256명 조사에서는 0.5Hz 미만의 횡방향 움직임이 메스꺼움과 가장 잘 연결됐습니다(Turner·Griffin 1999).

| 값 | 현재 | 유형 | 근거 |
| --- | --- | --- | --- |
| `fastTurnMps2` 빠른 회전 | 2.0m/s² | 연구·실측 | 앞뒤 기준과 같은 값. 실도로 안내 연구는 앞뒤·좌우에 같은 상한(1.89)을 씀(Xie 외 2026). 공개 데이터에서 회전의 상위 약 22% |
| `swingMps2` 반복 좌우 크기 | 0.9m/s² | 연구 | 횡방향 0.2Hz·1.0m/s²에서 9명 모두 증상(Souman 외 2026). 실도로 안내 연구의 상한 0.89(Xie 외 2026) |
| `swingWindowMs` | 30초 | 연구 | 횡방향 0.06Hz·2.0m/s²에서 10명 모두 증상. 다만 0.06Hz·1.0m/s²는 7명 중 3명으로 약함(Souman 외 2026) |
| `swingCount` | 3번 | 제품 판단 | 앞뒤 반복과 같은 정의. 연구 근거 없음 |
| `wheelbaseMeters` | 3.0m | 가정 | 차량 값을 주는 API가 없어 IONIQ 5 [공식 사양](https://www.hyundai.com/content/dam/hyundai/au/en/ecomm/ioniq5v3/IONIQ5_Specification_Guide_version3.pdf)을 씀 |
| `steeringRatio` | 14.26 | 가정 | IONIQ 5 미국 사양표(검색 요약으로만 확인, 원문 미확인). 공식 사양의 끝에서 끝 2.67회전(약 ±480°)이 에뮬레이터 범위 −470~500°와 일치 |
| `averageWindowMs`, `minAverageSpanMs`, `maxGapMs` | 1초, 0.5초, 1초 | 구현 판단 | 앞뒤 계산과 같은 구간 |
| `turnEndRatio` | 0.5 | 구현 판단 | 2.0 부근에서 값이 흔들려도 한 회전을 여러 번 세지 않게 하는 간격 |

추정의 한계:

- **차량 값이 다르면 추정값도 달라집니다.** 조향비 12.6~16, 축거 2.7~3.0m 범위라면 실제 값은 표시값의 약 0.9~1.3배입니다.
- **모델의 범위:** 이 식은 타이어 미끄러짐을 무시하며, 횡가속도 약 0.5g 미만에서 유효하다고 보고됩니다([Bou Ghosn 외 2025](https://arxiv.org/abs/2502.05479)가 인용). 기준값 2.0과 0.9는 이 안에 있습니다.
- **탑승자 체감과 다릅니다.** 좌석 위치, 머리 움직임, 차체 기울기는 반영하지 않습니다.

조향을 받지 못한 주행은 좌우 패턴이 없는 것이 아니라 판정하지 않은 것이므로, 상세 화면에 그렇게 표시합니다.

## 실측

### 실제 주행

공개 데이터 [VED](https://github.com/gsoh/VED)(미국 미시간 승용차, 2017~18)에서 약 1초마다 속도가 갱신된 28,300회 주행, 3,790시간, 328대에 앱과 같은 판정을 적용했습니다. 10분당 횟수는 60분 이상 기록된 281대의 중앙값입니다. 이 데이터에서 출발은 10분당 4.54회, 정차는 4.22회입니다.

| 기준 | 해당 비율 | 10분당 |
| --- | --- | --- |
| **빠른 출발 2.0** | 17.4~56.3% | 0.8~2.7회 |
| 버스 급출발 2.22 | 12.9~49.0% | 0.6~2.3회 |
| 택시 급출발 2.78 | 4.1~32.3% | 0.2~1.5회 |
| **큰 감속 2.0, 5초** | 26.4% | 1.07회 |
| 같은 값, 3초 | 17.3% | 0.69회 |
| 버스 급정지 2.5, 5초 | 12.5% | 0.48회 |
| 택시 급정지 3.89, 5초 | 1.1% | 0.03회 |

출발 비율이 범위인 이유는 기록 장치의 갱신 지연입니다. 속도 0 다음 첫 값이 20km/h를 넘기도 하는데 1초 만에 그 속도에 이를 수는 없어, 앱의 판정을 그대로 적용하면 출발이 급하게 잡힙니다. 그 값을 위쪽 추정으로, 처음 값이 10km/h 이하인 출발 58,630건(전체 109,516건)만 본 값을 아래쪽 추정으로 적었습니다. 아래쪽의 10분당 횟수는 비율에 출발 빈도를 곱한 값입니다. 아래쪽은 완만한 출발로 치우칠 수 있습니다.

| 반복 가감속 | 10분당 |
| --- | --- |
| **0.9, 30초, 3번** | 1.57회 |
| 0.9, 20초, 3번 | 0.90회 |
| 0.9, 30초, 4번 | 0.47회 |
| 0.8, 30초, 4번 | 0.59회 |
| 1.0, 30초, 4번 | 0.39회 |
| 0.9, 20초, 4번 | 0.15회 |

현재 값이면 세 패턴을 합쳐 10분당 약 3.4~5.3회 관찰됩니다. 공단의 택시 급정지 기준처럼 드문 값은 30분 주행의 비교에서 사건이 거의 남지 않아, 최근 주행 비교에도 쓰기 어렵습니다.

### 좌우 움직임 (GPS로 추정)

VED에는 조향과 횡가속도가 없어 GPS 방향 변화와 속도로 추정했습니다(4,790시간, 384대). GPS가 약 3초 간격이라 최고값이 낮게 나오고, 0.17Hz보다 빠른 흔들림은 보이지 않습니다. GPS 잡음이 값을 키우기도 합니다. 실제 값과 다른 대략의 규모로만 봅니다.

| 항목 | 결과 |
| --- | --- |
| 회전 빈도(0.5m/s² 이상) | 10분당 11.29회 |
| 회전별 최고값 | 중앙값 1.11, 상위 10% 2.71, 상위 5% 3.34m/s² |
| **빠른 회전 2.0** | 회전의 21.8%, 10분당 약 2.5회 |
| 2.5 / 3.0 기준 | 12.7% / 7.2% |
| **반복 좌우 0.9, 30초, 3번** | 10분당 0.18회 |
| 0.9, 30초, 4번 / 1.5, 30초, 3번 | 0.03회 / 0.03회 |

앞뒤 패턴과 합치면 10분당 약 6.1~7.9회 관찰됩니다. 반복 좌우 움직임은 공개 데이터의 지역(미시간)에서 드물고, 굽은 길이 많은 곳에서는 달라질 수 있습니다.

## 확인하지 못한 것

- **실차 신호.** 에뮬레이터 속도는 계단처럼 바뀌어 정확도를 판단할 수 없습니다. 실차에서 정차 직후 속도가 0에서 튀면 빠른 출발이 과하게 잡힙니다. 실차 기록으로 다시 측정합니다.
- **실차 조향.** 조향은 값이 바뀔 때만 들어오고 시각이 없어 도착 시각을 씁니다. 실차의 갱신 빈도와 지연, 조향각 정의는 확인하지 못했습니다.
- **차량 값과 승인.** 실제 축거와 조향비, App Market의 `CAR_DRIVE` 승인 여부는 확인하지 못했습니다.
- **어린이.** 위 연구는 모두 성인 대상입니다. 어린이 동승자에게 맞는지는 알 수 없습니다.
- **국내 승용차 주행.** 찾지 못했습니다. VED는 미국 자료입니다.
- **de Winkel 외(2023) 원문 표.** 자동 접속이 막혀 읽지 못했습니다. 1.23은 팀 논문 검증표의 본문 확인 기록, 0.89와 1.89는 Xie 외(2026)의 인용으로 확인했습니다.
- **탐지와 멀미의 관계.** 이 기준으로 잡은 관찰이 실제 멀미와 얼마나 관련되는지는 측정하지 않았습니다.
