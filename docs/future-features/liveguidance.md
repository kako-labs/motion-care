# liveguidance

담당: 주행 담당

구현한 것: 내비 위 안내 카드, 반복·간격·잔잔한 순간 판단, ON/OFF, 안내 이력 저장. 규칙의 근거는 [안내 카드의 근거](../guidance-card.md)에 있습니다.

후속 구현: 메시지 카드가 막힐 때의 앱 안 배너와 알림 센터. 알림음·음성, 환경 카드, 주행 시간 카드는 구현했습니다.

`feature/driving`에 구현하고, 다른 기능의 데이터는 data 모듈의 Repository로 읽습니다.

표시 방식과 문구 길이는 [화면 디자인 기록](../design.md)의 주행 중 안내 방식을 따릅니다.
