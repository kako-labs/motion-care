# 이야기 영상 내레이션판 (3분 15초)

무음 이야기 영상(3분 10초)에 내레이션과 배경음악을 얹은 판입니다. Remotion 프로젝트를 다시 렌더링하지 않고, 완성된 무음 영상 파일 위에 소리를 얹고 필요한 곳의 화면만 늘렸습니다.

| 파일 | 내용 |
| --- | --- |
| `motioncare-story-narrated.mp4` | 완성본. H.264, 1920×1080, 30fps |
| `narration.m4a` | 내레이션만 담은 트랙. 영상 0초에 맞춰 배치 |
| `lines.json` | 생성에 쓴 대본. 묶음 `b0`~`b6` 단위로 한 번에 생성 |
| `plan.json` | 문장별 시작·끝 시각과 화면을 늘린 위치 |

도구는 `../tools/narration/`에 있습니다.

## 무음판과 달라진 점

- 타이틀과 자막 28개를 한 목소리로 읽습니다. 마무리 화면에는 내레이션이 없습니다.
- 화면을 두 곳에서 멈춰 늘렸습니다. 타이틀 3.13초(첫 문장이 타이틀 위에서 끝나도록), 자막 11번 1.43초(자막이 3초뿐이라 문장이 들어가지 않음). 그만큼 전체가 4.57초 길어졌습니다.
- 무음판에 들어 있던 카드 알림음(원본 66.6초)은 뺐습니다. 자막 옆 '알림음' 표시는 화면에 남아 있습니다.
- 배경음악이 끝까지 깔리고 마지막 3초 동안 잦아듭니다.

## 목소리와 설정

- **음성:** ElevenLabs 웹 화면, 모델 Eleven v4, 목소리 `Kelee K - Seoul Narrator`, 안정성 50%, 유사성 75%.
- **후처리:** 음높이는 유지하고 빠르기 1.12배, 이어서 음높이를 반음 1.5개 낮춤(`voicefx.py`). Eleven v4 화면에는 속도 설정이 없어 생성 뒤에 맞췄습니다.
- **대본 표기:** 글자를 소리 나는 대로 적은 곳이 있습니다(`디로`, `피로`, `십 분`, `삼 회`). 자막 표기와 다르지만 읽는 소리는 같습니다.
- **생성 단위:** 문장을 하나씩 만들지 않고 묶음마다 빈 줄로 나눠 한 번에 생성한 뒤, 가장 긴 쉼에서 문장을 잘랐습니다.

## 배경음악

YouTube 오디오 보관함의 `Pulsar`(The Grey Room / Density & Time, 4분 8초)입니다. 보관함 표시는 "수익 창출 동영상을 포함한 모든 동영상에서 사용 가능, 저작자 표시는 필수 아님"입니다. 음원 파일은 저장소에 넣지 않았습니다. YouTube Studio의 오디오 보관함에서 내려받습니다.

뒤로 갈수록 커지는 곡이라 8초 창으로 음량을 고르게 눌러 내레이션의 약 1/4~1/5 크기로 맞췄습니다.

## 다시 만들기

Python 3와 PyAV, NumPy가 필요합니다. 문장 확인에는 faster-whisper를 씁니다.

```sh
# 1. 무음 영상에서 자막 시각과 화면 움직임을 읽습니다.
python tools/narration/scan.py <무음영상.mp4> work/scan.json

# 2. 묶음별 음성(mp3)을 voicefx.shift(path, 1.12, -1.5)로 처리해 work/clips/b0_el.wav ~ b6_el.wav로 저장하고,
#    narration/lines.json을 work/clips/에 복사합니다.

# 3. 문장이 대본대로 잘렸는지 받아쓰기로 확인합니다.
python tools/narration/pick_takes.py work/clips

# 4. 배치만 먼저 보고(--plan), 영상을 만듭니다.
python tools/narration/assemble.py <무음영상.mp4> work/clips work/scan.json <Pulsar.mp3> out/narrated.mp4 --plan
python tools/narration/assemble.py <무음영상.mp4> work/clips work/scan.json <Pulsar.mp3> out/narrated.mp4
```

`assemble.py`의 자막 구간(`SEGS`)과 타이틀·마무리 시각은 이 무음 영상에 맞춘 값입니다. 영상을 새로 렌더링해 자막 시각이 바뀌면 `scan.py`가 출력하는 구간으로 바꿔야 합니다.

## 확인한 것과 확인하지 않은 것

- 내레이션 전체를 받아쓴 결과가 대본과 순서·내용이 일치했습니다.
- 28개 자막마다 해당 문장이 읽히는 시점에 그 자막이 화면에 떠 있는 것을 프레임으로 확인했습니다(같은 배치를 쓴 이전 판 기준).
- 알림음 자리의 음량이 음악만 있는 구간과 같습니다.
- 듣기에 자연스러운지, 화면을 멈춘 두 곳이 어색하지 않은지는 사람이 직접 보고 들어야 합니다.
- 저장소에 넣은 도구는 경로를 인자로 받도록 고친 뒤 문법 검사만 했습니다. 고친 상태로 처음부터 끝까지 다시 돌려 보지는 않았습니다.
- 자막 8~12번 묶음은 다른 묶음보다 목소리가 조금 낮게 생성됐습니다(중간 음높이 약 207Hz, 나머지 약 220~226Hz).
