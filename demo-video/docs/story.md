# 이야기 영상 (MotionCareStory)

한 가족의 운행 한 번을 출발 전부터 다음 출발까지 실제 순서대로 따라가는 3분 10초(190초) 영상입니다. 3분 영상(`MotionCare3Min`, `docs/3min.md`)을 다시 만든 것입니다.

- **결과:** `out/motioncare-story.mp4` (1920x1080, 30fps, 알림음만). 영상과 녹화본(`public/rec/`)은 Git에 넣지 않습니다.
- **편집 파일:**
  - `src/story/scenes.ts`: 장면 한 줄이 하나입니다(녹화본의 어느 구간, 자막, 강조).
  - `src/story/Story.tsx`: 화면 구성입니다.

## 왜 다시 만들었나

이전 3분 영상에 대한 팀 피드백은 이랬습니다.

> 너무 확대한다거나, 초반에 뭔가 반짝반짝하면서 갑자기 지나가는 기능이 있다거나. 자연스러운 기능 소개와 진행 순서. 모든 게 다 부족했던 것 같다.

이전 영상을 프레임으로 보니 다음과 같았습니다.
- 장면마다 움직이는 확대가 있었고, 확대할 때 테두리가 빛났습니다.
- 앱 장면을 1.1~2.4배속, 주행 장면을 최대 4.7배속으로 돌렸습니다. 그래서 기능이 4~6초씩 지나갔습니다.

### 방향을 정한 근거

같은 상황 설명만 준 AI 페르소나 세 개에게 따로 의견을 받았습니다(2026-11-12). 실제 전문가가 아닙니다.
- 페르소나: 시연 영상 감독, 차량 HMI·UX 전문가, 공모전 심사위원
- 상황 설명: 공모전, 앱 기능, 촬영 소스, 제약, 위 피드백

**세 의견이 같았던 것**
- 한 운행을 P → D → P → 다음 출발 순서로 따라가고, 마지막 조언 화면에서 처음 장면과 이어지게 닫습니다.
- 주행이 가장 긴 구간입니다.
- 기능 몽타주 없이 문제 문장으로 시작합니다. 첫 렌더는 타이틀 없이 차량 화면으로 바로 시작했고, 사용자 결정으로 5초 타이틀(문제 문장 → 앱 이름)을 앞에 붙였습니다.
- 전체 화면을 고정하고, 왼쪽 속도·기어를 자르지 않습니다.
- 원인과 결과(기어, 탭, 카드)는 1배속으로 둡니다. 기다리는 구간은 컷하고 "n분 뒤"를 표시합니다.
- 자막은 한 번에 한 문장으로 쓰고, 장 이름을 늘 띄웁니다.
- 기록 장면은 방금 운행의 그래프로 잇습니다.
- 콘솔은 한 번만 보여 주고, 끝에 녹화 방식과 진단 아님을 밝힙니다.

**나머지 결정**

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 확대 | 글자가 작은 장면 하나에만 고정 1.5배 | 페르소나 셋 중 둘이 1.5배 이하를 허용함 |
| 내레이션(TTS) | 넣지 않음 | 사용자 결정 |
| 배경음악 | 없이 알림음만 | 사용자 결정 |
| 공기 카드 | 뺌 | 사용자 결정. 촬영 날 서울 대기질이 '보통'이라 카드가 뜰 조건이 아니었고, 15분 간격 규칙 때문에 패턴 카드와 같은 운행에 띄울 수 없음 |

## 구성 (3:10)

| 시간 | 장 | 장면 | 녹화본 |
| --- | --- | --- | --- |
| 0:00~0:05 | 타이틀 | 남색 바탕에 문제 문장, 이어서 앱 아이콘·이름·한 줄 소개. 빛 효과 없이 나타나고 사라짐 | |
| 0:05~0:29 | 출발 전 | 내비가 앞에 있는 주차 상태에서 하단 바로 앱을 엶. 홈의 출발 조언("1.7회에서 0.5회로"), 함께 타는 사람, 좌석 | 본 테이크 |
| 0:29~1:20 | 주행 | 기어 D로 기록 시작(콘솔 작은 창 5초), 내비, 정차 직전 큰 감속 3번, 내비 위 카드와 알림음, 카드가 저절로 사라짐 | 본 테이크 |
| 1:20~1:52 | 도착 | P, 3분 뒤 자동 종료, 서아의 이동 평가(보호자가 대신, 별 3개, 출발·정차). 저장하면 바로 다음 사람 화면으로 넘어가서 저장 직전에 끊음 | 본 테이크 |
| 1:52~2:38 | 기록 | 방금 운행: 그래프의 감속 3번, 세 번째 감속, 차 안 환경, 서아 3/5와 주행 중 안내 1번. 운전자 프로필의 3주 흐름 | 상세 테이크, 본 테이크 |
| 2:38~3:00 | 다음 출발 | 홈 조언("0.4회에서 1.9회로"), 왜 이 조언인지, 계산 방법(1.5배 확대) | 본 테이크 |
| 3:00~3:10 | 마무리 | 앱 아이콘과 이름, 기록 → 카드 → 평가 → 조언, 영상에 나온 차량 기능, 녹화 방식과 진단 아님 | |

**화면 규칙**
- **화면:** Pleos 화면(2560x1440)을 1568x882로 같은 자리에 둡니다. 아래 자막 띠에는 장 이름, 큰 문장, 작은 줄이 들어갑니다.
- **강조:** 주변을 조금 어둡게 하고 얇은 테두리를 그립니다. 빛 번짐과 깜빡임은 없습니다. 속도 표시와 카드에는 테두리만 씁니다.
- **누른 위치:** 녹화 스크립트가 누른 위치와 시각을 적어 두고 옅은 원으로 그립니다. 에뮬레이터의 시스템 터치 표시(`show_touches`)는 화면에 나오지 않았습니다.
- **소리:** 카드 알림음 한 번뿐입니다. 녹화한 에뮬레이터 소리를 26dB 키우고 클리핑을 막았습니다.
- **속도:** 모든 장면이 1배속입니다. 건너뛴 구간은 "1분 뒤", "3분 뒤"로 표시합니다.

## 녹화 (tools/rec)

AVD `pleos`(emulator-5600)만 씁니다. 실행 조건은 `docs/3min.md`의 녹화 절과 같습니다(오디오, gRPC 8590, Virtual Console 8796).

1. **기록을 맞춥니다.** 저장소 루트에서 `python3 docs/pleos-emulator/tools/film_takes.py restore`를 실행해 시연용 20건으로 시작합니다.
2. **본 테이크:** `python3 story_take.py <폴더>` (약 13분)
   - 순서: 내비 앞 → 하단 바로 앱 → 좌석 → 기어 D → 하단 바로 내비 → 40km/h, 약 75초 간격으로 세게 정차 3번 → 카드 → 3분 주행 → P → 3분 뒤 자동 종료 → 이동 평가 → 프로필 → 홈 → 왜 이 조언인가요 → 계산 방법
   - 운행 하나와 평가 하나가 기록에 더해집니다.
3. **상세 테이크:** 본 테이크 바로 뒤, 기록을 되돌리기 전에 찍습니다. `python3 detail_take.py <폴더>` (약 50초)
   - 순서: 기록 탭 → 방금 운행 → 세 번째 감속 → 아래로 두 번
   - 이동 평가는 한 사람을 저장하면 다음 사람 화면으로 넘어가서, 본 테이크에서는 상세로 가지 못했습니다. 그래서 따로 찍습니다.
4. **기록을 되돌립니다:** `film_takes.py restore`
5. **맞춥니다:** 에뮬레이터 시계 − 호스트 시계(ms)를 재서 넘깁니다(11/12 측정 −1046~−1052).
   - 명령: `python3 tools/rec/prep_story.py <본 테이크> -1048 <상세 테이크>`
   - 결과: `public/rec/{story_pleos,story_console,detail_pleos}.mp4`, `public/rec/story_audio.wav`, `src/data/{story,detail}.json`
   - 알림음은 앱 로그(`GuidanceSound: started`) 시각에 맞춥니다(`docs/3min.md`의 시각 맞춤과 같음).

## 확인한 것

- **자막:** 화면에 보이는 것만 적었습니다. 숫자는 모두 앱 화면의 값입니다.
  - 출발 전 조언: 1.7회 → 0.5회
  - 다음 출발 조언: 0.4회 → 1.9회
  - 오늘 운행: 7분, 정차 직전 큰 감속 3회
  - 서아 3/5, 주행 중 안내 1회
- **이야기 문장:** "운전하는 사람은 괜찮은데, 뒷자리 아이는 멀미를 합니다"는 앱이 측정한 사실이 아니라 이야기의 전제입니다.
- **카드:** 세 번째 정차로 차가 선 지 약 4.2초 뒤에 알림음이 났습니다(콘솔 기록 279.4초, 앱 로그 283.6초). 규칙은 `GuidancePolicy`의 10분 안 같은 패턴 3번과 정차 뒤 잔잔한 순간입니다. 카드와 알림음은 1배속 그대로입니다.
- **마무리의 차량 기능:** 영상에 나온 것만 적었습니다. 차량 속도, 기어, 공조·온도(운행 상세의 차 안 환경), 위치(바깥 대기질), 내비 위 알림 카드입니다.

## 확인하지 못한 것

- 실차. 모든 화면은 에뮬레이터입니다.
- 내비 지도가 그려지지 않는 에뮬레이터라 내비 화면은 비어 있습니다.
- 노트북 창 크기에서 앱 글자가 읽히는지는 사람이 직접 보지 않았습니다.
